# Riverbend Family Clinic — Device Security Standard

> FICTIONAL SAMPLE DOCUMENT created to demonstrate ComplianceGuard AI.

## Laptops

All clinic laptops use BitLocker full-disk encryption (AES-256) before they are
issued to staff. Laptops that are lost or stolen must be reported to the IT
Manager within one hour.

## EHR database

The EHR vendor hosts the database and states that data is encrypted at rest.

## Removable media

The weekly off-site backup drive is not encrypted. Replacing it with an encrypted
drive is planned for next quarter.

## Mobile phones

Clinic-issued phones require a six-digit passcode.
