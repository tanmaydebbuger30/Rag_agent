## 1. Security official

The IT Manager, Dana Ortiz, is designated as the clinic's HIPAA Security Officer.
The Security Officer is responsible for developing, implementing and maintaining
the clinic's security policies and procedures, and reports to the Practice
Administrator. Staff can contact the Security Officer at security@riverbend.example
or extension 214; this contact information is published on the staff intranet.

## 2. Security incidents

This section is the clinic's incident response policy. A security incident means
any attempted or successful unauthorized access, use, disclosure, modification or
destruction of information, or interference with system operations.

The Security Officer leads the incident response. All workforce members must report
any suspected or known security incident to the Security Officer or the IT help
desk within 1 hour of noticing it. Examples include a lost laptop, a phishing email
that was clicked, or a patient record opened by mistake.

When an incident is reported, IT will contain the incident (for example by
isolating the affected computer or disabling the account) and mitigate harmful
effects where practicable. Systems are restored from backup when needed.

## 3. Security evaluation

The Security Officer performs an annual security evaluation of these policies and
of the clinic's technical safeguards, with help from an external consultant every
second year.
