# ComplianceGuard AI

Evidence-based readiness gap analysis for the HIPAA Security Rule Access Control
standard (45 CFR § 164.312(a)). Upload policies, or run the fictional sample
clinic, to see each requirement assessed with quoted evidence, citation
verification and human review.

This is a portfolio demo: it is not a legal determination of compliance, and
assessments are stored only until the Space restarts.

Source code, design notes and evaluation results:
https://github.com/tanmaydebbuger30/Rag_agent
